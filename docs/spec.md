## 1. 「## 公開前チェックとブラウザテスト」の、ブラウザでの実行テストの項目

「ぞろぞろは左上の長押しで設定 /」の直後に、次を足す。

```
 ゲームが増えたとき(9個までは、スクロールしなくても1画面に全タイルが見える。20個でも縦・横とも全タイルに届く) /
```

## 2. 「## 作りの決まり」の、画面の隅のボタンの行の直後

次の1行を足す。

```
- トップのタイル: `layoutTiles()`(index.html)が、ゲーム数と画面の大きさに合わせて列数を決め、1画面に収める(一辺104px以上)。収まらないほど多いときだけ縦にスクロールし、下に続くときは下端がうっすら消えて合図になる。**`html`/`body` に `touch-action: none` を付けない**(一覧を指でスクロールできなくなり、下のゲームが見えなくなる)。ゲームを足しても index.html は直さない
```
